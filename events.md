# SUEC Events

This file lists recommended event names for SaaS and software usage analytics.

Use these names directly when they match your product. When your product has a domain-specific object, adapt the object while keeping the same grammar.

## Activation

First setup or first value moment.

```text
account_created
workspace_created
project_created
onboarding_started
onboarding_completed
integration_connected
first_value_completed
```

Domain examples:

```text
textile_pattern_activated
crm_pipeline_created
ai_assistant_connected
```

## Engagement

Repeated product usage.

```text
project_opened
document_opened
document_edited
document_saved
dashboard_opened
search_performed
tool_used
template_selected
settings_updated
```

Domain examples:

```text
textile_pattern_edited
invoice_line_edited
crm_contact_updated
```

## Output

Created, generated, exported, published, or shared value.

```text
document_exported
report_generated
asset_downloaded
page_published
link_shared
file_uploaded
file_imported
```

Domain examples:

```text
textile_pattern_exported
invoice_exported
campaign_published
```

## Collaboration

Team and multiplayer activity.

```text
invite_sent
member_joined
comment_created
comment_resolved
approval_requested
approval_completed
role_updated
handoff_completed
```

## Friction

Blocked intent, failure, permissions, or limits.

```text
action_blocked
save_blocked
export_failed
import_failed
permission_denied
quota_limit_reached
payment_failed
integration_failed
```

Domain examples:

```text
textile_pattern_save_blocked
textile_pattern_export_failed
crm_import_failed
```

## Revenue

Commercial lifecycle events.

```text
checkout_started
purchase
trial_started
trial_converted
subscription_started
subscription_upgraded
subscription_downgraded
subscription_cancelled
subscription_reactivated
```

## Ecommerce Compatibility

Keep known ecommerce funnel names when tracking commerce:

```text
view_item
add_to_cart
remove_from_cart
begin_checkout
purchase
refund
```

Use SUEC around the software experience itself:

```text
pricing_page_opened
checkout_started
subscription_started
invoice_exported
```
